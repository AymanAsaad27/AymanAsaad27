## Featured Projects

**Fine-Tuning Open-Source LLMs for Medical Question Answering** (undergraduate thesis)
Fine-tuned Mistral-7B and LLaMA-3-8B with QLoRA and compared SFT, DPO, ORPO, GRPO, and RAG on MedMCQA. Accuracy improved from 43.1% to 57.8% (Mistral-7B) and from 56.0% to 62.6% (LLaMA-3-8B). Included confidence calibration, error analysis, cross-domain evaluation on MedQA-USMLE, and a Gradio interface for model comparison.
*Python, PyTorch, Hugging Face Transformers, PEFT, TRL, RAG, Gradio*

**SCU FLY: Flight Route Optimization and Ticket Meta Search**
End-to-end system for large-scale flight data ingestion (HDFS, Hive) and fare analysis with Spark. Graph-based routing balances price, layover duration, and total travel time. Includes an AI chatbot and a React front end with price-trend charts and route maps.
*Hadoop, Spark, PySpark, React, Folium, Leaflet.js*

**Lung Cancer Detection from CT Scans**
CNN classifier for CT scans (lung cancer vs. healthy) reaching 85% test accuracy on an 80/20 split, packaged in a web interface for image upload and prediction.
*Python, TensorFlow, Keras*

**Smart Dormitory System**
Desktop management application with role-based access control, payments, room allocation, and reporting, built on a layered architecture with a normalized MySQL schema.
*C#, .NET Windows Forms, MySQL*

**Automated Email and Contact Scraper**
